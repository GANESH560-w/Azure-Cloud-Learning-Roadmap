# Azure Cloud Learning Roadmap

## Azure Part 1

| Priority | Category | Learn | Important Azure Services |
|---:|---|---|---|
| **1** | Azure Fundamentals | Azure basics, subscriptions, regions, resources | Azure Portal, Resource Groups, Subscriptions |
| **2** | Compute | VMs, sizing, disks, availability, scaling | Azure Virtual Machines, VM Scale Sets, Availability Zones |
| **3** | Networking | VNet, subnet, IP, NSG, routing | VNet, Subnet, NSG, Route Table, Public IP, NAT Gateway |
| **4** | Network Connectivity | VPN, peering, private connectivity | VPN Gateway, VNet Peering, Private Link, ExpressRoute |
| **5** | Identity & Access | Authentication, authorization, RBAC | Microsoft Entra ID, Azure RBAC, Managed Identity |
| **6** | Storage | Blob, Files, disks, replication | Storage Account, Blob Storage, Azure Files, Managed Disks |
| **7** | Load Balancing | L4/L7 traffic distribution | Azure Load Balancer, Application Gateway |
| **8** | DNS | DNS zones, records, private DNS | Azure DNS, Private DNS |
| **9** | Security | Firewall, WAF, DDoS, secure access | Azure Firewall, WAF, DDoS Protection, Azure Bastion |
| **10** | Key & Secrets | Secrets, certificates, encryption keys | Azure Key Vault |
| **11** | Monitoring | Metrics, logs, alerts, troubleshooting | Azure Monitor, Log Analytics, Application Insights |
| **12** | Backup & DR | Backup, restore, disaster recovery | Azure Backup, Azure Site Recovery |
| **13** | Database | Managed databases, backups, HA | Azure SQL Database, Azure Database for PostgreSQL |
| **14** | Containers | Docker, images, registries | Azure Container Registry, Azure Container Apps |
| **15** | Kubernetes | AKS, deployments, networking, scaling | Azure Kubernetes Service (AKS) |
| **16** | DevOps / CI-CD | Pipelines, builds, releases | Azure DevOps, Azure Pipelines, GitHub Actions |
| **17** | Infrastructure as Code | IaC, state, modules, variables | Terraform, Bicep |
| **18** | Automation | CLI, PowerShell, scripting | Azure CLI, Azure PowerShell, Automation Account |
| **19** | Messaging | Queues, events, asynchronous communication | Service Bus, Event Grid, Event Hubs |
| **20** | Cost Management | Budgets, cost analysis, optimization | Azure Cost Management, Azure Advisor |
